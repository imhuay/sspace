## 基础模板

> 常见有两类模板: **开区间 `[l,r)`** 和 **闭区间 `[l,r]`**; 本文以 **闭区间** 为主;

> 一般编程语言标准库中提供的二分查找会使用 **开区间**, 但是在尝试一段时间后, 开区间在具体问题上容易混淆判断条件 (个人经验);

### **查找型二分 `while l <= r`**
```python
l, r = ...      # 初始区间
ret = ...       # l 或 r, 初始答案
while l <= r:
    m = (l + r) // 2
    if check(m):          # 满足条件
        ans = m             # 保存答案
        l = m + 1           # 继续探索更大值
        # r = m - 1         # 继续探索更小值
    else:                 # 不满足条件, 收缩区间
        r = m - 1   
        # l = m + 1
```
<!-- - 模板 **`while l <= r`**: -->
- **语义**: 只要区间里还有元素, 就继续检查;
    - 因为当 `l == r` 时, 区间里还有一个候选点需要检查, 所以必须继续循环;
- **退出时**: `l > r`, 区间为空;
- **适用场景**: 目标值, 边界, 条件最值;

### **收缩型二分 `while l < r`**
```python
l, r = ...      # 初始区间
while l < r:
    m = (l + r) // 2
    if condition(m):
        r = m           # m 仍可能是答案, 因此不能收缩到 m - 1
    else:
        l = m + 1
# 退出时 l == r，就是答案
```
- **语义**: 区间里有至少两个元素时, 就继续检查;
    - 当区间收缩到单点时, 这个点就是答案, 不需要再判定;
- **退出时**: `l == r`, 收缩到单点, 该点就是答案;
- **适用场景**: 最值, 峰值;

## 经典问题

### 左边界查找
- 返回 **第一个** `≥ x` 的位置.

<details><summary><b>🔸 闭区间 <code>[l, r]</code></b></summary>

```python
def bisect_left(a, x):
    """"""
    l, r = 0, len(a) - 1            # 闭区间 [0, n-1]
    while l <= r:                   # 结束时 l = r + 1
        mid = l + (r - l) // 2
        if a[mid] < x:
            l = mid + 1
        else:
            r = mid - 1             # 保证闭区间
    return l
```

</details>

<details><summary><b>🔸 开区间 <code>[l, r)</code></b></summary>

```python
def bisect_left(a, x):
    """"""
    l, r = 0, len(a)                # 开区间 [0, n)
    while l < r:                    # 结束时 l = r
        mid = l + (r - l) // 2
        if a[mid] < x:              # 小于目标值时, 往右找
            l = mid + 1
        else:
            r = mid
    return l
```
> _参考 `from bisect import bisect_left`_

</details>

### 右边界查找

- 返回 **第一个** `> x` 的位置.
    > ⚠️ _注意是 `>`, 是不包括 `x` 的._
- 与 **左边界查找** 只有一个区别: `if a[mid] < x` → `if a[mid] <= x`

<details><summary><b>🔸 闭区间 <code>[l, r]</code></b></summary>

```python
def bisect_right(a, x):
    """"""
    l, r = 0, len(a) - 1
    while l <= r:
        mid = l + (r - l) // 2
        if a[mid] <= x:         # 小于等于目标值时, 往右找
            l = mid + 1
        else:
            r = mid - 1
    return l
```

</details>

<details><summary><b>🔸 开区间 <code>[l, r)</code></b></summary>

```python
def bisect_right(a, x):
    """"""
    l, r = 0, len(a)
    while l < r:
        mid = l + (r - l) // 2
        if a[mid] <= x:         # 小于等于目标值时, 往右找
            l = mid + 1
        else:
            r = mid
    return l
```
> _参考 `from bisect import bisect_right`_

### 旋转数组 📌

> 🚨 **备忘**: 旋转数组相关的 4 道题, 目前使用的模板是在测试了各种模板后, 保留下来改动最小的版本 (统一使用 **闭区间** `[l, r]` 和 `nums[m] > nums[r]` 判断左侧有序); 
> **其他模板总会一些特殊用例无法通过, 太耗费精力, 不再深入研究, 记录以备忘**.

- **旋转数组特性**: 
    - 数组被分为两段有序区间;
        <div align='center'><a href='_formulas/二分查找备忘/f_001.js.tex'><img src='_formulas/二分查找备忘/f_001.js.svg'/></a></div>

- **思路**:
    - 关键: 判断中点 `nums[m]` 落在哪段有序区间;
        - ~~**如果 `nums[l] <= nums[m]`, 则左侧有序**, 检查目标是否在 `[l, m)` 内;~~
            > ~~⚠️ 如果数组 **无重复**, `<` 也可以; 但如果 **有重复**, 必须 `<=`.~~
        - 当 `nums[m] > nums[r]` (或 `nums[l] <= nums[m]`) 时, 左侧一定有序, 检查目标是否在 `[l, m)` 内;
        - 反之, 右侧有序, 检查目标是否在 `[m, r)` 内.

<details><summary><b>🔸 搜索旋转排序数组 (无重复, 闭区间实现)</b></summary>

> [33. 搜索旋转排序数组 - 力扣 (LeetCode) ](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

**闭区间 `[l, r]`**
```python
l, r = 0, len(nums) - 1

while l <= r:
    m = (l + r) // 2

    if nums[m] == target:
        return m

    if nums[m] > nums[r]:     # 此时, 左侧一定有序
        # 左侧有序
        if nums[l] <= target < nums[m]:
            r = m - 1
        else:
            l = m + 1
    else:
        # 右侧有序
        if nums[m] < target <= nums[r]:
            l = m + 1
        else:
            r = m - 1

return -1
```

</details>

<details><summary><b>🔸 搜索旋转排序数组 (有重复, 闭区间实现)</b></summary>

> [81. 搜索旋转排序数组 II - 力扣 (LeetCode) ](https://leetcode.cn/problems/search-in-rotated-sorted-array-ii/)

- **思路**:
    - 在旋转排序数组中搜索的关键是判断哪边有序;
    - 在有重复元素的旋转排序数组中, **有且只有一种情况无法判断哪边有序**, 即 `nums[l] == nums[m] == nums[r-1]` 时;
        - `nums[l] != nums[m], nums[m] != nums[r-1]` 时, 普通情况, 略;
        - `nums[l] == nums[m], nums[m] != nums[r-1]` 时, 左侧一定有序;
            - `nums[l] == nums[m]` 只有两种情况: 
                1. `m` 落在左侧有序区间, `[l,m]` 区间内全等;
                2. `m` 落在右侧有序区间, 此时一定有 `nums[m] == nums[r-1]`, 矛盾;
        - 同理, `nums[l] != nums[m], nums[m] == nums[r-1]` 时, 右侧一定有序.
    - 当无法判断哪边有序时, **收缩区间**
        - `nums[l] == nums[m] == nums[r-1]` 有且只有两种情况:
            ```txt
            a a a b c a a a a a a a a
            l →         m         ← r

            a a a a a a a a b c a a a
            l →         m         ← r
            ```
        - 操作方法相同:
            - `l += 1`
            - `r -= 1`

**闭区间 `[l, r]`**
```python
l, r = 0, len(nums) - 1

while l <= r:
    m = (l + r) // 2

    if nums[m] == target:
        return True
    
    if nums[l] == nums[m] == nums[r]:   # 收缩区间
        l += 1
        r -= 1
    elif nums[m] > nums[r]:             # 此时, 左侧一定有序 (收缩区间后)
        if nums[l] <= target < nums[m]:
            r = m - 1
        else:
            l = m + 1
    else:                               # 右侧一定有序
        if nums[m] < target <= nums[r]:
            l = m + 1
        else:
            r = m - 1

return False
```

</details>

#### 旋转数组的最小值

- **旋转数组**:
    <div align='center'><a href='_formulas/二分查找备忘/f_002.js.tex'><img src='_formulas/二分查找备忘/f_002.js.svg'/></a></div>

- **思路**:
    - 最小值一定在右侧有序区间, 即 $a_0$;
    - 中点落到左侧时, 就移动 `l → m + 1`;
    - ⚠️ 注意, **中点落到右侧时**, 因为不能排除 `nums[m]` 是最小值的情况, 所以不能直接移动 `r → m - 1`, 只能 `r → m`.

<details><summary><b>🔸 寻找旋转排序数组中的最小值 (无重复, 闭区间实现)</b></summary>

> [153. 寻找旋转排序数组中的最小值 - 力扣 (LeetCode) ](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)

**闭区间 `[l, r]`**
```python
l, r = 0, len(nums) - 1

while l < r:
    # 如果当前区间整体有序, 直接返回最左端
    if nums[l] < nums[r]:
        return nums[l]

    m = (l + r) // 2

    if nums[m] > nums[r]:  # 左侧一定有序, 最小值在右侧
        l = m + 1
    else:
        r = m              # 注意这里不能 - 1

return nums[l]
```
- `nums[m] <= nums[r]` (即右侧有序时), 不能排除 `nums[m]` 是最小值的情况, 所以不能直接把 `r` 移动到 `m - 1`, 只能移动到 `m`;

</details>

<details><summary><b>🔸 寻找旋转排序数组中的最小值 (有重复, 闭区间实现)</b></summary>

> [154. 寻找旋转排序数组中的最小值 II - 力扣 (LeetCode) ](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii/)

### 条件最值 (判定型二分) 📌
> 最大可行值 / 最小可行值

- **问题特点**:
    - 判定型二分一般都是在求某个条件下的 **极值** (最小可行值或最大可行值);
    - 在区间 `[l, r]` 上, 定义一个 **单调** 的判定函数 `check(m)`;
    - 根据单调性, 二分搜索边界;

<!-- - **在 **二分查找** 的模版上, **添加判定函数 `check(m)`**, **检查中点是否满足目标****; -->
- **模板代码**:
    ```python
    l, r = min_ret, max_ret     # 初始化答案*闭区间*
    ret = ...   # 初始化为 l 或 r

    while l <= r:  # 当 l == r 时, 区间内还有一个点需要检查, 所以必须 <=
        m = l + (r - l) // 2
        if check(m):          # 判断是否满足条件
            ret = m              # 满足, 保存答案
            l = m + 1            # 寻找更大的值
            # r = m - 1          # 寻找更小的值
        else:                 # 不满足, 收缩区间
            r = m - 1         
            # l = m + 1
    
    return ret
    ```

    > 🚨 对 **闭区间** `[l, r]`, 当 `l == r` 时, **区间内还有一个点需要检查**, 所以循环条件必须是 `while l <= r`;

    > 在中间过程保存答案 `ret = m` 之后, 就可以安全的把 `l` 或 `r` 移动到 `m ± 1`; 否则有些问题因为 **边界也可能是答案**, 就只能把 `l` 或 `r` 移动到 `m`;

#### 平方根

<details><summary><b>🔸 整数平方根</b></summary>

> [69. x 的平方根 - 力扣 (LeetCode) ](https://leetcode.cn/problems/sqrtx/description/)
```python
ret = 0

l, r = 0, x          # 闭区间 [l, r]
while l <= r:
    m = (l + r) // 2

    if m ** 2 <= x:  # check
        ret = m
        l = m + 1
    else:
        r = m - 1

return ret
```

</details>

<details><summary><b>🔸 浮点平方根</b></summary>

```python
def sqrt(x, eps=1e-6):

    l, r = 0, max(1, x)  # 闭区间 [l, r]

    while r - l > eps:
        m = (l + r) / 2
        if m * m <= x:
            l = m
        else:
            r = m
    return l        # l 或 r 都可以, 此时它们几乎相等
```

</details>

#### 在 D 天内送达包裹的能力 (最小化最大值)
> [1011. 在 D 天内送达包裹的能力 - 力扣 (LeetCode) ](https://leetcode.cn/problems/capacity-to-ship-packages-within-d-days/)

- **题目大意**:
    ```txt
    有一批包裹，每个有重量，必须按顺序装船。船每天只能运一次，容量有限。
    问：最少需要多大容量，才能在 days 天内运完所有包裹？
    ```

<details><summary><b>🔸 Python</b></summary>

```python
# 判定函数：能否以 c 容量在 days 天内运完
def check(c):
    d, s = 1, 0
    for w in weights:
        assert w <= c       # 装载量至少要比单个货物大
        if s + w > c:
            d += 1
            s = 0
        s += w
    return d <= days

l, r = max(weights), sum(weights)
ret = r
while l <= r:                   # 闭区间
    m = (l + r) // 2
    if check(m):
        ret = m                 # 保存答案
        r = m - 1               # 可行, 尝试更小
    else:
        l = m + 1
return ret
```

</details>

#### 两球之间的磁力 (最大化最小值)
> [1552. 两球之间的磁力 - 力扣 (LeetCode) ](https://leetcode.cn/problems/magnetic-force-between-two-balls/)

- **题目大意**:
    ```txt
    在一条数轴上有若干个篮子，每个篮子的位置由数组 position 给出。
    现在要在这些篮子里放置 m 个球，要求使得 任意两球之间的最小距离尽可能大。返回这个最大化后的最小距离
    ```

<details><summary><b>🔸 Python</b></summary>

```python
# 判定函数：能否以最小间距 d 放下 m 个球
def check(d: int) -> bool:
    pre = position[0]
    cnt = 1
    for cur in position[1:]:
        if cur - pre >= d:
            cnt += 1
            pre = cur
            if cnt >= m:
                return True
    return False

position.sort()  # 先排序

l, r = 1, position[-1] - position[0]
ret = 1  # 初始化为最小值
while l <= r:
    m = (l + r) // 2
    if check(m):
        ret = m      # 可行, 记录答案
        l = m + 1    # 尝试更大值
    else:
        r = m - 1    # 不可行, 缩小范围
return ret
```

</details>

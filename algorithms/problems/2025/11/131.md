<summary><b>思路: 子集型回溯</b></summary>

- **当前操作**
    - 判断 `s[i:j+1]` 是否为回文子串, 加入 `path`
- **子问题**
    - 从下标 `s[i:]` 开始构造回文分割
- **下一个子问题**
    - 从下标 `s[j+1:]` 开始构造回文分割

<details><summary><b>Python</b></summary>

```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        
        ans, path, n = [], [], len(s)

        def dfs(i):
            if i == n:
                ans.append(path[:])

            for j in range(i, n):
                t = s[i: j + 1]
                if t == t[::-1]:
                    path.append(t)
                    dfs(j + 1)
                    path.pop()
        
        dfs(0)
        return ans
```
